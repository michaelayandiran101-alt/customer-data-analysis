# Customer Data Analysis

## Overview
This project analyzes customer purchasing behavior using Python and pandas. The analysis focuses on customer spending, purchasing frequency, demographics, cities, and spending categories.

## Tools Used
- Python
- pandas

## Analysis Performed
- Calculated total customer spending
- Calculated average customer spending
- Identified the highest-spending customer
- Calculated average purchases per customer
- Analyzed spending by city
- Analyzed purchases by city
- Identified customers spending over $300
- Analyzed customers with more than 5 purchases
- Calculated spending per purchase
- Identified the oldest customer
- Identified the customer with the fewest purchases
- Analyzed spending by gender
- Created spending categories based on total spending

## Key Skills Demonstrated
- Python programming
- pandas DataFrames
- Data filtering
- GroupBy analysis
- Aggregation
- Conditional logic
- Lambda functions
- Feature engineering
- Data analysis

## Key Results
- Total customer spending: $2,985
- Highest individual spending: $650
- Highest spending customer: Customer 108
- Fewest purchases: Customer 109
- Spending was analyzed across Atlanta, Marietta, and Kennesaw
- Customers were categorized as Low, Medium, or High spenders
